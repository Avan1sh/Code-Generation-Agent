The deterministic half of the agent runs entirely in your browser. Paste any Pydantic code and see exactly what the pipeline’s v1 anti-pattern scanner flags — the same eight rules, applied the same way. Below that, 65 recorded agent runs you can step through attempt by attempt.

What cannot run here, and why

This page is static hosting — no server. The full agent needs two things a browser cannot provide: an LLM API key, which must never ship in public JavaScript, and a Python subprocess running pytest against generated code inside a resource-limited sandbox.

So nothing here calls a model. What you get instead is real: the anti-pattern scanner is a faithful port of the actual rules, and every replay below is recorded output from a committed run, not a simulation.

To watch the full loop run live — generate, gate, sandbox, reflect, retry — there is a hosted version with a real backend at selfcorrect-agent-demo.onrender.com. It sleeps when idle, so the first request takes a minute to wake.

Anti-pattern scanner

In the pipeline this node runs before any sandboxed execution, so a v1-syntax answer is rejected without spending a test run on it. A single finding fails the gate.

solution.py

    What this port covers. All eight v1 anti-pattern rules, matched per line, exactly as in agent/nodes/static_check.py. The real gate additionally runs ast.parse for syntax errors and pyflakes for undefined names — both need Python, so neither runs here. It also deliberately does not fail on unused imports: that is style noise, and failing on it would penalise solutions for reasons unrelated to v1-versus-v2 correctness.
